# Arroyo Fold camera stills

Open [the gallery](index.html) to browse 22 native 1920 × 1080 frames. Select a photograph to inspect it at full resolution.

[The pool facade](hero.jpg) uses the start screen’s 50° vertical field of view with the interface hidden. [The arrival view](start.jpg) shows the title and controls. Interior and terrace views use the 61° walking lens. Six views show the house after dark.

[Camera data](gallery.json) records the position, orientation, exposure, time setting, and lens for each frame.
